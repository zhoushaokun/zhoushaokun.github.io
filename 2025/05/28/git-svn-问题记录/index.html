svn 类

svn: E120106: ra_serf: The server sent a truncated HTTP response body.

原因：svn 客户端在遇到大量大文件时会出现的 timeout 的失败情况，

解决：cd 到 %appdata%\subversion\servers 下，调大 http-timeout 值

参考：https://stackoverflow.com/questions/27267742/why-do-i-get-svn-e120106-ra-serf-the-server-sent-a-truncated-http-response-b
