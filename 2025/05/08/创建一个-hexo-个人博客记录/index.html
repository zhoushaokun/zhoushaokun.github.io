Created2025-05-08|Updated2025-05-21
|Post Views:

最近突发奇想，想要搭建一个自己的博客，写一些平时的技术总结和感想，同时也发现 hexo 是一个流行且方便的博客框架，所以我就使用 hexo + bufferfly + pages 搭建了一个个人博客。并将过程中一些步骤简述如下，希望能够给各位有类似需求的朋友提供帮助。
摘要：本文会首先介绍 hexo 的使用和主题安装，其次以 atom pages 为例介绍 hexo 的部署。

注意：hexo 大致可以分为两部分：

  • 主库（上文 hexo 创建的 myblog 目录）
  • 博客页面库(public 目录)

我理解主库相当于一个工具台+文章的原件+若干配置。我也十分推荐使用 git 仓库对主库进行管理，并推送到远程托管平台（可以设置为私有仓库），因为我也看到有些 hexo 的用户反馈自己换电脑导致博客原件丢失的情况，托管到云平台进行数据备份会保证数据不因为硬件问题丢失。

具体步骤，比如我们在 github 创建一个 myblog 的仓库后，我们可以 cd 到 当前 myblog 主库下进行数据的推送，通过简单步骤即可完成主库数据备份。

博客页面库保存着对外可以直接访问的公共资源，我们会将其发布到公共的 git 仓库下，作为 xx pages 的数据源，这只需要我们创建一个空的公开仓库，然后将其配置到 hexo 的配置下，具体下文会再讲述。

总结

不同的 pages 方案具有不同的个性化设置，此处要注意查看相关的文档或者指引设置，避免踩坑。此外，atom pages 不支持绑定域名，如果有绑定域名需要的朋友可以更换其他方案，比如 github，或者如果有条件可以将博客资源放到 cvm 上，然后申请一个域名指向 cvm 的地址，博主刚开始着手写博客，便先以 atom pages 开始，希望后续能够坚持写作！
